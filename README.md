SouthCoast Eats 014 – Portable Server

Use SouthCoast-Eats-Server.exe to serve the app locally. Open the Laptop URL first, then use the Wi-Fi URL from an iPhone on the same network.

This build keeps the larger text and repaired data package. Recommendation ranking now gives explicit category-specialization weight to Recommended and uses category fit as a small tie-breaker for the other sorts. Restaurant quality/deal/speed fields are still provisional and must be reconciled before production.
